# 🤖 AI Chat Assistant (Flutter + Gemini API)

An intelligent AI-powered chatbot built with **Flutter** that leverages the **Google Gemini API** to answer user queries in real time. The application features a clean and responsive interface with support for both **Light** and **Dark** themes, providing a smooth and modern user experience.

---

## ✨ Features

* 💬 AI-powered conversations using the **Gemini API**
* 🌙 Beautiful **Light & Dark Mode** support
* ⚡ Real-time response generation
* 📱 Clean, responsive, and intuitive Flutter UI
* ⏳ Loading indicator while the AI generates a response
* 🎨 Modern Material Design interface

## 🚀 How It Works

1. Launch the application.
2. Enter your question in the chat box.
3. The app sends the prompt to the **Gemini API**.
4. A loading indicator is displayed while the response is being generated.
5. The AI-generated answer is presented in the chat interface.
